Paste this in terminal whenever u want to access mysql in terminal
(This command opens the MySQL CLI and asks for your password so you can access MySQL and execute SQL queries directly in the terminal.
In short: Terminal → MySQL CLI → MySQL Server → Execute SQL queries)

& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p





CLI = Command-Line Interface
It lets you interact with a program by typing commands instead of clicking buttons.
For example:
- MySQL CLI: Run SQL commands in the terminal.
- MySQL Workbench: Use a graphical interface with buttons, menus, and an SQL editor
